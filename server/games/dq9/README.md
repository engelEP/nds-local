# Dragon Quest IX

The server covers Sellma's shop and the extra quests.

Sellma stocks the counter from the shop week that is current on this server. Each visit shows a handful of items from that week. The quest download brings the extra quests and the guests that travel with them.

## Shop calendar

The shop changes every Friday at 8:00 in the morning, UTC. One week lasts seven days, and the fifty-two weeks then start over. The next round begins one day earlier than the one before.
